GoldPulse AI V8

V8 saves the Twelve Data API key locally on this device and provides Edit/Clear controls.
It is also a PWA: when hosted on HTTPS, Chrome can install it to the Android home screen and open it like an app.

A downloaded file:// HTML cannot reliably install a PWA/service worker. Host this folder on an HTTPS site, open it in Chrome, then choose Install/Add to Home Screen.
